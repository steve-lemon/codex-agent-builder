# Sample Tool Resources

This folder contains the deterministic sample/mock tool pack.

Files:
- `TOOLS.yml`: resource-backed tool-pack metadata for mock customer support, ops, and research tools

Why it lives here:
- `sample-tools` is primarily a sample/demo and test support pack used across multiple skills.
- It is not a true long-term shared domain resource, so we keep it isolated under `data/tools/` until a real shared/common area is needed.
